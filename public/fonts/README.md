# Fonts

Self-hosted so that renders never depend on fonts.googleapis.com (offline, proxies, cloud containers).

- Instrument Serif regular + italic (titles and statements) — SIL Open Font License 1.1
- Bricolage Grotesque 700/800 (labels, cards, captions) — SIL Open Font License 1.1
- JetBrains Mono 700/800 (numbers, code, sources) — SIL Open Font License 1.1

Loaded in `src/theme.ts` with the FontFace API and `delayRender`.
